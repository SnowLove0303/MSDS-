# 型号与标准法规清单（玩具/消费品安全）

> 用途：冠志/国彩水性材料下游应用（玩具涂料、油墨、胶粘剂、食品接触等）
> 所涉**检测标准与限量法规**集中清单。服务研发部型号开发与 MSDS 合规。
> 归档目录：`标准原文归档/型号与标准/`。全文 PDF 已归入 `法规原文归档/出口市场/` 及本目录。

| 元素 | 涂层限量 (mg/kg) |
|---|---|
| 锑 Sb | 60 |
| 砷 As | 25 |
| 钡 Ba | 1000 |
| 镉 Cd | 75 |
| 铬 Cr | 60 |
| 铅 Pb | 90 |
| 汞 Hg | 60 |
| 硒 Se | 500 |

**CPSC 铅额外要求**：
- 16 CFR 1303：玩具/儿童用品**涂层**总铅 ≤ 90 ppm
- CPSIA：儿童用品**基材**总铅 ≤ 100 ppm

## 四、卤素清单（无卤要求）

**测试方法**：EN 14582（卤素含量测定）。
**无卤限值**（参考 IEC 61249-2-21 / IPC-4101C）：

| 卤素 | 无卤限量 |
|---|---|
| 氯 Cl | ≤ 900 ppm |
| 溴 Br | ≤ 900 ppm |
| 氟 F | 报告值（部分标准含） |
| 碘 I | 报告值（部分标准含） |
| **总卤素（Cl+Br）** | ≤ 1 500 ppm |

> 主要针对电子产品（PCB）与部分消费品。玩具领域无统一强制「无卤」标准，
> 常由买家（如宜家）合同约定。氟/碘一般不作硬性限制。

## 五、全氟烷基化合物（PFAS）清单

**欧盟状态**：ECHA 于 2023-02-07 提交**通用限制提案**（universal restriction），
5 国（丹麦/德国/荷兰/挪威/瑞典）联合提交，拟限制 **>10 000 种 PFAS**：
- 提案限值：单一 PFAS ≤ **25 ppb**；PFAS 总和 ≤ **250 ppb**
- 计划时间线：2025 年欧盟委员会决策 → 2027 年起分行业实施（含 12 年过渡期）
- 2025-09 ECHA 发布修订版草案（收窄部分豁免）

**重点受控 PFAS 类别**（REACH SVHC / POPs 已受限）：
| 物质 | CAS | 现状 |
|---|---|---|
| 全氟辛烷磺酸 PFOS | 1763-23-1 | 斯德哥尔摩公约（POPs）禁用 |
| 全氟辛酸 PFOA | 335-67-1 | POPs 禁用（2020-07 起） |
| 全氟己烷磺酸 PFHxS | 355-46-4 | POPs 新增（2023） |
| C6-C14 全氟羧酸 PFCAs | — | REACH 附件 XVII 条目 68 |
| GenX 及其盐 | 13252-13-6 | SVHC 候选清单 |

## 六、游离双酚 A（BPA）

**玩具**：(EU) 2017/898 修订玩具指令——**迁移限值 ≤ 0.04 mg/L**（EN 71-10/11 方法，2018-11-26 起适用）。
**食品接触材料**：(EU) 2018/213——食品接触清漆/涂层迁移 ≤ 0.05 mg/kg。
**BPA 危害**：内分泌干扰物（ED），SVHC 候选清单物质；2024 年欧盟 ECHA 拟进一步收紧。

> 📌 附件：`欧盟玩具BPA限制 2017-898.pdf`

## 六B、玩具铬(VI)限值修订

**(EU) 2018/725**（2019-11-18 起适用）修订玩具指令附件 II 第三部分第 13 点铬(VI)限值：

| 玩具材料 | 铬(VI)限值 (mg/kg) |
|---|---|
| 干燥/脆/粉末状 | 0.02 |
| 液态/粘稠 | 0.005 |
| 刮削状 | **0.053**（原 0.2 → 收紧） |

> 📌 附件：`欧盟玩具铬VI限值修订 2018-725.pdf`

## 七、多环芳烃（PAHs）标准

**REACH 附件 XVII 条目 50**（EU 1272/2013）——8 种 PAH：

| PAH | 简称 | CAS |
|---|---|---|
| 苯并(a)芘 | BaP | 50-32-8 |
| 苯并(e)芘 | BeP | 192-97-2 |
| 苯并(a)蒽 | BaA | 56-55-3 |
| 屈 | CHR | 218-01-9 |
| 苯并(b)荧蒽 | BbFA | 205-99-2 |
| 苯并(j)荧蒽 | BjFA | 205-82-3 |
| 苯并(k)荧蒽 | BkFA | 207-08-9 |
| 二苯并(a,h)蒽 | DBAhA | 53-70-3 |

**限值**：
- **玩具/儿童用品**（橡胶/塑料部件接触皮肤或口腔）：每种 PAH ≤ **0.5 mg/kg**
- 一般消费品（同上接触条件）：每种 PAH ≤ 1 mg/kg
- 填充轮胎用填充油：BaP ≤ 1 mg/kg；PAH 总和 ≤ 10 mg/kg

## 八、欧盟 REACH 法规

**全文**：EC 1907/2006 官方综合版已归档（`法规原文归档/出口市场/`）。
**相关附件**（已归档于 `法规原文归档/出口市场/REACH/`）：
- **附件 XIV** 授权物质（59 项）
- **附件 XVII** 限制物质（83 项）——含 PAH（条目50）、邻苯二甲酸酯（条目51）、有机锡（条目20/63）
- **SVHC 候选清单**（247/253 项）

**邻苯二甲酸酯（玩具专用，REACH 附件 XVII 条目 51/52）**：
| 物质 | 条目 | 玩具限值 |
|---|---|---|
| DEHP、DBP、BBP、DIBP | 51 | 塑化材料 ≤ 0.1%（永久禁用，不可豁免） |
| DINP、DIDP、DNOP | 52 | **可放入口中**的玩具/儿童用品塑化材料 ≤ 0.1% |

> 「可放入口中」定义：玩具的任一部件尺寸可放入儿童口中（目测）且可被吸吮或咀嚼。

## 九、有机锡化合物清单（REACH 附件 XVII 条目 20）

**范围**：三取代有机锡（TBT/TPT）、二取代（DBT）、单取代、DOT。
**限值**（条目 20 第 4/5/6 点）：

| 物质 | 限值 | 适用 |
|---|---|---|
| 三取代有机锡（TBT 三丁基锡、TPT 三苯基锡） | 锡含量 > 0.1%（wt）禁用 | 所有物品，2010-07-01 起 |
| 二丁基锡 DBT 化合物 | > 0.1%（wt tin）禁用 | 公众用品/混合物，2012-01-01 起 |
| 二辛基锡 DOT 化合物 | > 0.1%（wt tin）禁用 | 接触皮肤/眼睛的衣物、手套等，2012-01-01 起 |
| 有机锡作杀生物剂 | 禁止 | 自由缔合涂料、船舶防污、工业水处理 |

> **玩具有机锡迁移限值**（玩具指令 2009/48/EC 附件 II Part III）：
> Organic tin 迁移限量 Cat.I 0.9 / Cat.II 0.2 / Cat.III 12 mg/kg
> （已在已归档玩具指令 PDF 中确认，与 REACH 附件 XVII 条目20/63 互补）。

## 十、新玩具安全法规（重大更新）

**⚠️ (EU) 2025/2509 新玩具安全法规（TSR）**——完整 PDF 已归档（82页）：
- 2025-11-26 通过，2025-12-12 公报发布
- 将**取代并废除玩具安全指令 2009/48/EC**（24 个月过渡期后适用）
- 引入**数字产品护照（DPP）**与 CE 标志数码化

**附件 II Part III 化学品核心禁止**（比旧指令大幅收紧）：
| 类别 | 禁止内容 |
|---|---|
| CMR 物质 | 致癌/致突变/生殖毒性 1A、1B、2 类禁止 |
| 内分泌干扰物（ED） | 人类健康 ED 类别 1、2 禁止 |
| 特定靶器官毒性 | 单次/反复暴露 STOT 1 类禁止 |
| 呼吸致敏 | 类别 1 禁止 |
| 皮肤致敏 | 类别 1A 禁止 |
| **PFAS** | **故意使用全氟和多氟烷基物质禁止** |
| **双酚类** | 附录 D 所列双酚（含 BPA）禁止 |

> 📌 附件：`欧盟新玩具安全法规 TSR 2025-2509.pdf`
