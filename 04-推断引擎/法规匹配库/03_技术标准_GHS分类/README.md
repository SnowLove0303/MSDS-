# 象形图库（GHS 危害象形图 + TDG 运输标志）

> 本目录是 **MSDS 象形图的权威归档**（单一事实来源），从 `法规匹配库/象形图库` 迁入 `标准原文归档/`。
> 供 MSDS 规范化推导技能（`msds-inference-write`）、覆写引擎及标签编写引用。

## 两套象形图体系（易混淆，务必区分）

| 体系 | 用途 | 所在子目录 | 命名 |
|---|---|---|---|
| **GHS 危害象形图**（GB 30000 系列） | MSDS **第2部分 标签要素** | `标准象形图/`、`单个象形图/` | `GHS01_爆炸物.png` ~ `GHS09_环境危害.png` |
| **TDG 运输标志**（《危险货物运输建议书》） | MSDS **第14部分 运输信息** | `运输标志TDG/` | `TDG1.1.png` / `TDG2.1.png` / … / `TDG8.png` |

> 一套是 GHS 危害分类用的 9 个象形图；一套是运输危险货物分类用的第1~9类运输标志，**不是同一套**。
> 同一物质（如腐蚀性）在 S2 用 GHS05（危害象形图），在 S14 用 TDG8（运输标志）。

## 颜色版本说明（重要）

- **标准原文版（本目录）**：`标准象形图/GHS01~09` 为**黑白印刷版**——裁剪自 GB 30000.1-2024 通则「图1 危险符号」
  （标准正文印刷为黑白，非缺色），适合**核对分类对应关系**、追溯标准原文出处。
- **原始提取版（`原始提取/`）**：从各分部分 PDF 附录 B 直接渲染的**原始位图，含 112 张彩色版**，
  用于按标准定位任一象形图的真实样式。
- **MSDS 渲染版（彩色）**：技能 `templates/pictograms/` 下 9 个 GHS 为 **960×960 彩色标准图**
  （红边菱形，符合 GHS 外观），**MSDS Word 嵌入一律用彩色版**——黑白标准版不得直接嵌入 MSDS。

## 其他归档文件

- `pictograms_index.json`：**全量 187 张** GB 30000 各分部分附录 B 象形图位图的来源索引（标准号/页码/危害类别/坐标），用于按标准定位任一象形图。
- `原始提取/`：187 张位图（从 GB 30000 各 PDF 渲染，含 112 张彩色），文件名 `{标准号}_p{页码}_{序号}.png`。

- `单个象形图/GHS01_原始.png` ~ `GHS09_原始.png`：从 GB 30000 标准 PDF 提取的原始位图。
- `标签样例_GB30000.30-2025.png`、`图1_危险符号_GB30000.1-2024.png`、`图2_皮肤刺激物象形图_GB30000.1-2024.png`、`退敏爆炸物象形图_GB30000.30-2025.png`：最新标准（GB 30000.1-2024 / GB 30000.30-2025）象形图与标签样例。
- `_contact_sheet.png`：187 张索引图的缩略拼合（检索用）。

## 与技能的关系

- 技能 `msds-inference-write` 的工作副本在 `templates/pictograms/`（17 个 PNG：GHS01~GHS09 彩色 960×960 + TDG 系列），**MSDS Word 渲染取用彩色版**（技能副本）；
  本目录是**标准原文权威档案**（黑白标准版 + 原始提取彩色位图 + TDG），用于核对出处与样式。
  若需替换技能副本图，务必用彩色标准图（红边菱形），不得用本目录黑白版。
- 提取/重建脚本：`法规匹配库/tools/pictogram_extract.py`（从 GB 30000 PDF 渲染位图到 `原始提取/` 并生成索引；bbox 去重 + 短边 600px 渲染）。

## 使用

content.json 中引用方式（渲染时从技能 `templates/pictograms/` 取图）：
```json
{"t": "pictogram", "code": "GHS05"},   // S2 标签要素：皮肤腐蚀1B
{"t": "pictogram", "code": "TDG8"}     // S14 运输信息：UN 2735 第8类
```
