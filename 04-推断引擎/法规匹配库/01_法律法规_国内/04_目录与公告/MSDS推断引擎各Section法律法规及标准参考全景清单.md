# MSDS 推断引擎各 Section 法律法规及标准参考全景清单

> **制定背景与用途**：本清单系统梳理了化学品安全技术说明书（MSDS / SDS）在规范化推导、诊断、合规重写与自动生成全生命周期中，各个 Section（1~16 节）所必须依赖的国家法律、行政法规、国家强制性标准（GB）、推荐性标准（GB/T）、卫生标准（GBZ）、交通行业标准（JT/T）以及国际权威公约规范。为推断引擎提供底层法理支撑与判定基准。

## 一、总纲：MSDS / SDS 全局编制框架与通用标准

编制与推导 MSDS 必须首先遵循国内外通用的顶层编制框架标准：

| 规范/标准编号 | 标准名称 | 法律/技术效力及核心要求 |
|---|---|---|
| **GB/T 16483-2008** | 《化学品安全技术说明书 内容和项目顺序》 | **国家标准（总框架）**：规定 SDS 的 16 大节标准名称、顺序与基本信息结构（等同采用 ISO 11014:2009）。 |
| **GB/T 17519-2013** | 《化学品安全技术说明书编写指南》 | **国家标准（编写指南）**：明确 16 节中每个子项的详细编写深度、格式规范、数据缺失处理原则及逻辑自洽性要求。 |
| **UN GHS 紫皮书 Rev.10 (2023)** | 《全球化学品统一分类和标签制度》第十修订版 | **联合国国际规范**：全球 GHS 分类准则、危险公示（象形图、信号词、H/P代码）及 SDS 编制的顶层基准。 |
| **EU Regulation 2020/878** | 欧盟 REACH 法规附件 II（SDS 编制要求修订版） | **欧盟强制法规**：欧盟市场 SDS 格式规范，明确纳米材料、内分泌干扰物（EDCs）及超细颗粒的特殊公示要求。 |
| **US OSHA 29 CFR 1910.1200** | 美国危险公示标准（HCS 附录 D） | **美国联邦法规**：美国工作场所化学品危险公示及 16 节 SDS 强制标准。 |

## 二、Section 1 ~ Section 16 逐节法律法规与标准参考全景

### Section 1：化学品及企业标识 (Identification)

*核心推导目标：产品中英文命名规范、24h 应急咨询电话合法性、供应商主体信息与推荐/限制用途。*

| 适用法规 / 标准 | 核心条款与技术要求 |
|---|---|
| **GB 15258-2009**《化学品安全标签编写规定》 | 第 4.1.7 条明确规定：化学品安全技术说明书与标签上**必须提供境内 24 小时应急咨询服务电话**；委托专业机构的应注明机构名称。 |
| **GB 13690-2009**《化学品分类和危险性公示 通则》 | 规范化学品标识、商品名、通用名及化学名称的命名一致性。 |
| **《危险化学品登记管理办法》**（原安监总局令第 53 号） | 危化品生产与进口企业必须��应急管理部登记中心登记并取得应急咨询服务电话。 |
| **GB/T 17519-2013** 第 3.1 节 | 明确要求列出推荐用途、限制用途、供应商全称、地址、邮编、联系电话、传真、电子邮件及最初编制/修订日期。 |

### Section 2：危险性概述 (Hazard(s) Identification)

*核心推导目标：基于 S3 成分与 S9 理化数据，通过分类逻辑自动判定 GHS 危险类别、生成象形图、信号词、危险性说明（H码）及防范说明（P码）。*

| 适用法规 / 标准 | 核心条款与技术要求 |
|---|---|
| **GB 30000.1-2024**《化学品分类和标签规范 第1部分：通则》 | 我国 GHS 分类总则最新标准，规定化学品分类总体原则、危险公示要素及判定程序。 |
| **GB 30000.2-2013 ~ GB 30000.29-2013** | **物理危险（2~17 部分）**：爆炸物、易燃气体/液体/固体、自燃、自热、氧化性、有机过氧化物、金属腐蚀物等。<br>**健康危害（18~27 部分）**：急性毒性、皮肤腐蚀/刺激、严重眼损伤/刺激、呼吸/皮肤致敏、生殖细胞致突变性、致癌性、生殖毒性、特异性靶器官毒性（STOT SE/RE）、吸入危害。<br>**环境危害（28~29 部分）**：水生环境急慢性危害、危害臭氧层。 |
| **GB 30000.30-2025** | 《化学品分类和标签规范 第30部分：退敏爆炸物》（国家最新分类规范）。 |
| **GB 15258-2009** | 规定 GHS 危险性说明（H代码）与预防、应急、储存、废弃防范说明（P代码）的组合与省略规则。 |
| **GB 13690-2009** | 确定危险性公示要素（象形图、信号词、危险性说明、防范说明）的通用排版与匹配规则。 |

---

### Section 3：成分/组成资料 (Composition / Information on Ingredients)

*核心推导目标：物质/混合物识别、CAS 登记号校验、组分浓度截断值（Cut-off values）过滤、商业机密合规申报。*

| 适用法规 / 标准 | 核心条款与技术要求 |
|---|---|
| **《危险化学品目录（2015版 / 2026年调整版）》** | 国家安全监管核心名录（含 2833 条目），判定各组分是否属于法定危险化学品及剧毒化学品。 |
| **GB/T 17519-2013** 第 3.3 节 | **组分浓度截断值判定规则**：<br>• 急性毒性 / 皮肤眼刺激 / STOT / 水生危害：组分含量 **≥ 1.0%** 必须列出；<br>• 致癌性 / 生殖毒性 / 致突变性 / 呼吸或皮肤致敏：组分含量 **≥ 0.1%** 必须列出；<br>• 含有职业接触限值（OEL）的组分不论浓度均须列出。 |
| **《新化学物质环境管理登记办法》**（生态环境部令第 12 号） | 判定组分是否列入《中国现有化学物质名录》（IECSC），未列入需按新化学物质合规管理。 |
| **IUPAC 与 CAS 命名规范** | 化学品中文规范名称与国际唯一 CAS 登记号的一一对应校验。 |
| **商业机密保护规则**（GB/T 17519 第 3.3.3 条） | 允许对非危害性或特定专利组分保留商业机密（注明“商业机密”或“Trade Secret”），但其危害性类别与防护措施不得隐瞒。 |

### Section 4：急救措施 (First-aid Measures)

*核心推导目标：根据组分毒理与理化特性推导吸入、皮肤、眼睛、食入急救步骤，明确禁止催吐原则及医生特殊提示。*

| 适用法规 / 标准 | 核心条款与技术要求 |
|---|---|
| **GB/T 17519-2013** 第 3.4 节 | 明确按“吸入、皮肤接触、眼睛接触、食入”分项列出；明确最重要的急慢性症状；规定眼睛冲洗时间不得少于 15 分钟。 |
| **WS 444-2014**《化学品中毒医疗救治技术导则》 | 国家卫生行业标准：规范化学灼伤、刺激性气体中毒、有机溶剂中毒等现场急救救治技术规范。 |
| **GBZ 71-2013**《职业性急性化学物中毒诊断标准（总则）》 | 规定急性化学物中毒的现场救治原则、特效解毒剂应用（如阿托品、解磷定等）及医疗对症处理要点。 |
| **急救铁律** | 强腐蚀性物质（强酸强碱）及低黏度烃类溶剂（易发生吸入性肺炎）**严禁催吐**。 |

---

### Section 5：消防措施 (Fire-fighting Measures)

*核心推导目标：依据 S9 闪点与 S3 溶剂特性推导合适灭火剂（水雾/抗溶性泡沫/干粉/CO2）、禁用灭火剂、燃烧爆炸特别危害及消防员防护。*

| 适用法规 / 标准 | 核心条款与技术要求 |
|---|---|
| **GB 50016-2014 (2018年版)**《建筑设计防火规范》 | 依据闪点与燃烧性确定火灾危险性分类（甲、乙、丙、丁、戊类液体/固体）。 |
| **GB 17914 / 17915 / 17916-2013** | 《易燃易爆 / 腐蚀性 / 毒害性商品储存养护技术条件》中的火灾扑救与灭火隔离规范。 |
| **GB 50140-2005**《建筑灭火器配置设计规范》 | 针对水溶性极性溶剂（如乙醇、丙酮等）必须指定**抗溶性泡沫（AR-AFFF）**、干粉或二氧化碳灭火器。 |
| **GB/T 17519-2013** 第 3.5 节 | 明确列出特别危险性（如密闭容器受热爆炸、毒性热分解产物 NOx、CO、HCN 等）及消防废水防流失环保要求。 |

---

### Section 6：意外泄漏措施 (Accidental Release Measures)

*核心推导目标：推导作业人员防护装备、应急阻隔、消除火源、吸附收集材料（惰性吸附剂）及防次生环境污染措施。*

| 适用法规 / 标准 | 核心条款与技术要求 |
|---|---|
| **GB/T 17519-2013** 第 3.6 节 | 规范作业人员防护措施、应急程序、环境保护措施及泄漏化学品收容、清除方法。 |
| **GB 50483-2019**《化工建设项目环境保护设计标准》 | 化工企业事故水池、应急截流阀门及防下水道/地表水体扩散的环保工程规范。 |
| **《突发环境事件应急管理办法》**（环境保护部令第 34 号） | 化学品突发环境污染事件的现场处置与报告程序，严禁直接排入城市雨水/污水管网。 |

---

### Section 7：操作处置与储存 (Handling and Storage)

*核心推导目标：推导安全操作防范（防静电接地、局部排风、密闭操作）、禁配物隔离储存、库房温湿度控制及防爆电气要求。*

| 适用法规 / 标准 | 核心条款与技术要求 |
|---|---|
| **GB 15603-2022**《危险化学品仓库储存通则》 | **国家强制性标准**：规定危化品分类储存、禁配物隔离贮存矩阵（隔离/隔开/分离贮存）、堆垛间距及限量要求。 |
| **GB 12158-2006**《防止静电事故通用导则》 | 易燃易爆溶剂输送与灌装过程中的静电接地、跨接及流速限制（防静电集聚）。 |
| **GB 17914 / 17915 / 17916-2013** | 各类化学品的储存温度、相对湿度控制及通风防潮具体参数。 |
| **《危险化学品安全管理条例》**（国务院令第 591 号） | 第二十条至第二十七条：危化品储存专用仓库、专人管理、出入库核查登记及监控报警制度。 |

---

### Section 8：接触控制/个人防护 (Exposure Controls / Personal Protection)

*核心推导目标：匹配国家职业接触限值（PC-TWA / PC-STEL / MAC）、工程控制措施及个体防护装备（PPE）标准。*

| 适用法规 / 标准 | 核心条款与技术要求 |
|---|---|
| **GBZ 2.1-2019 + 2022年第1号修改单** | **国家职业卫生强制标准**：规定工作场所化学有害因素职业接触限值（包含 359 种化学物质的 PC-TWA、PC-STEL、MAC 及皮、敏、癌标识）。 |
| **GBZ 2.2-2007** | 《工作场所有害因素职业接触限值 第2部分：物理因素》（噪声、高温等）。 |
| **GB 39800.1-2020**《个体防护装备配备规范 第1部分：总则》 | **国家强制性标准**：按作业场所危害风险评估并配备合规的呼吸器、防护手套、护目镜及防护服。 |
| **呼吸防护标准** | `GB 2626-2019`（防颗粒物呼吸器）、`GB 2890-2009`（自吸过滤式防毒面具）、`GB/T 18664-2002`（呼吸防护用品的选择、使用与维护）。 |
| **眼面与手部身体防护** | `GB 14866-2006`（个人用眼护具技术要求）、`GB 24541-2009`（手套防化学品渗透）、`GB 24539-2021`（化学防护服）。 |
| **国际接触限值补充** | `ACGIH TLVs (2024)`（美国政府工业卫生学家会议限值）、`EU IOELVs`（欧盟职业接触限值指令 2000/39/EC 等 5 批指令）。 |

### Section 9：物理和化学特性 (Physical and Chemical Properties)

*核心推导目标：理化指标标准化定义、测试方法依据、单位统一化，以及行业挥发性有机物（VOC）有害物质限量合规判定。*

| 适用法规 / 标准 | 核心条款与技术要求 |
|---|---|
| **GB/T 17519-2013** 第 3.9 节 | 规定必须列明的 18 项理化参数（外观、气味、pH、熔点、沸点、闪点、蒸发速率、易燃性、爆炸极限、蒸气压、蒸气密度、相对密度、溶解性、分配系数、自燃温度、分解温度、黏度等），缺项标“无数据”或“不适用”。 |
| **国家理化测试方法标准** | `GB/T 21844-2008`（闪点测定 快速平衡闭杯法）、`GB/T 21853-2008`（化学品 沸点测定）、`GB/T 21845-2008`（水溶解度测定）、`GB/T 21860-2008`（凝固点测定）。 |
| **涂料行业 VOC 限量强制标准** | **GB 30981.1-2025**《涂料中有害物质限量 第1部分：建筑涂料》<br>**GB 30981.2-2025**《涂料中有害物质限量 第2部分：工业涂料》<br>**GB 18581-2020**《木器涂料中有害物质限量》<br>**GB 18582-2020**《建筑用墙面涂料中有害物质限量》 |
| **胶粘剂与油墨限量标准** | **GB 33372-2020**《胶粘剂挥发性有机化合物限量》<br>**GB 38507-2020**《油墨中挥发性有机化合物(VOCs)含量的限值》 |

### Section 10：稳定性和反应性 (Stability and Reactivity)

*核心推导目标：推导化学稳定性、危险反应可能性、应避免的条件（高温/火源）、禁配物矩阵及危险分解产物。*

| 适用法规 / 标准 | 核心条款与技术要求 |
|---|---|
| **GB/T 17519-2013** 第 3.10 节 | 必须明确：反应活性、化学稳定性、危险反应可能性、应避免的条件、禁配物及危险分解产物（含正常使用与火灾条件）。 |
| **GB 15603-2022** 附录 A | 化学品相互禁配物对照表（如强氧化剂与有机可燃物、强酸与强碱、遇水反应物与水分隔离等）。 |
| **GB/T 21578-2008** | 《危险品 反应性试验方法》（评估聚合放热、分解反应动力学风险）。 |

---

### Section 11：毒理学资料 (Toxicological Information)

*核心推导目标：各组分与混合物毒理学数据整合（急性经口/经皮/吸入 LD50/LC50、刺激腐蚀、致敏、CMR、STOT、吸入性）。*

| 适用法规 / 标准 | 核心条款与技术要求 |
|---|---|
| **GB 30000.18 ~ 30000.27-2013** | 健康危害 10 大分类标准的毒理学判据与分类阈值。 |
| **GBZ/T 240.1 ~ 240.29-2011** | 《化学品毒理学评价程序和试验方法》（国家标准毒理试验技术规范）。 |
| **OECD 毒理学测试准则** | `OECD 401/420/423/425`（急性经口毒性）、`OECD 404`（急性皮肤刺激/腐蚀）、`OECD 405`（急性眼刺激/腐蚀）、`OECD 406/429`（皮肤致敏试验 LLNA）、`OECD 471`（Ames 细菌致突变试验）。 |
| **IARC 致癌物名录** | 国际癌症研究机构致癌物分类（Group 1 人类致癌物、Group 2A 极可能致癌、Group 2B 可能致癌、Group 3 无法分类）。 |

### Section 12：生态学信息 (Ecological Information)

*核心推导目标：生态毒性（鱼类、溞类、藻类 LC50/EC50）、生物降解性、生物富集系数（BCF / log Kow）及土壤迁移性。*

| 适用法规 / 标准 | 核心条款与技术要求 |
|---|---|
| **GB 30000.28-2013** | 《化学品分类和标签规范 第28部分：对水环境的危害》（急慢性水生毒性分类准则）。 |
| **GB 30000.29-2013** | 《化学品分类和标签规范 第29部分：对臭氧层的危害》（消耗臭氧层物质 ODP 评估）。 |
| **国家生态毒性试验标准** | `GB/T 21807-2008`（鱼类急性毒性试验）、`GB/T 21809-2008`（大型溞急性活动抑制试验）、`GB/T 21805-2008`（淡水藻生长抑制试验）。 |
| **OECD 生态毒理与降解标准** | `OECD 201`（藻类生长抑制）、`OECD 202`（溞类急性活动抑制）、`OECD 203`（鱼类急性毒性）、`OECD 301A-F`（快速生物降解性试验）。 |

### Section 13：废弃处置 (Disposal Considerations)

*核心推导目标：废弃物危险特性判定、危险废物代码（HW代码）匹配、安全处置方法与环保合规禁止性条款。*

| 适用法规 / 标准 | 核心条款与技术要求 |
|---|---|
| **《中华人民共和国固体废物污染环境防治法》**（2020年修订版） | 第七章危险废物污染环境防治特别规定（危废全过程管理、严禁随意倾倒）。 |
| **《国家危险废物名录（2025年版）》** | **国家生态环境部最新名录**：准确识别危废类别代码（如涂料与油墨废弃物 **HW12**、废有机溶剂 **HW06**、表面处理废物 **HW17**、含醚废物 **HW40** 等）。 |
| **GB 18597-2023**《危险废物贮存污染控制标准》 | 危险废物在厂区内暂存的防风、防雨、防晒、防渗漏及标识规范。 |
| **GB 18484-2020**《危险废物焚烧污染控制标准》 | 废化学品高温焚烧无害化处置排放控制要求。 |

### Section 14：运输信息 (Transport Information)

*核心推导目标：多维度合规核验（国内危化品、易制毒、易制爆、重点监管、新化学物质，以及出口欧盟 REACH / CLP / RoHS）。*

| **《重点管控新污染物清单（2023年版）》** | 生态环境部列管的持久性有机污染物（POPs）及内分泌干扰物。 |
| **欧盟 REACH 法规 (EC 1907/2006)** | 校验是否含有：<br>• **SVHC 高度关注物质**（最新 247 项清单）；<br>• **Annex XIV 授权物质清单**；<br>• **Annex XVII 限制物质清单**（如邻苯二甲酸酯、壬基酚聚氧乙烯醚 NPEO 等）。 |
