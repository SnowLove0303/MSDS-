# GB/T 17519-2013 混合物健康及环境危害组分浓度限值（推导判据核心）

> 来源：GB/T 17519-2013《化学品安全技术说明书 编写指南》第 3.3.2 节表 1。
> 用途：判断 (a) S3 是否需列出某危险组分；(b) 混合物层面是否构成某危害类别。

| 危险性种类 | 浓度限值 (%) |
|---|---|
| 急性毒性（经口/经皮/吸入） | ≥ 1.0 |
| 皮肤腐蚀/刺激 | ≥ 1.0 |
| 严重眼睛损伤/眼睛刺激性 | ≥ 1.0 |
| 呼吸或皮肤过敏 | ≥ 0.1 |
| 生殖细胞突变性 类别1 | ≥ 0.1 |
| 生殖细胞突变性 类别2 | ≥ 1.0 |
| 致癌性 | ≥ 0.1 |
| 生殖毒性 | ≥ 0.1 |
| 特异性靶器官系统毒性-一次接触 | ≥ 1.0 |
| 特异性靶器官系统毒性-反复接触 | ≥ 1.0 |
| 吸入危害 类别1 | ≥ 10 且运动黏度 ≤ 20.5 mm²/s (40℃) |
| 吸入危害 类别2 | ≥ 10 且运动黏度 ≤ 14 mm²/s (40℃) |
| 对水环境的危害 | ≥ 1.0 |

## 应用规则（推导混合物分类）
1. **含量比较**：把某危险成分含量 vs 上表限值；达到即该成分对混合物该危害"有贡献"。
2. **总体判定**：多个成分可能共同贡献同一危害（尤其水环境危害），需把各危险成分含量加总评估是否跨过 ≥1.0% 或 ≥10% 门槛。
3. **浓度区间处理**：S3 常给区间（如 1-5%、0.5-3%）。判定时：
   - 用上限判断"是否可能构成危害"（保守）；
   - 用下限判断"是否必然构成危害"（确定）；
   - 若不确定，SDS 中可写"按最保守原则补充警示"或按供应商配方核算。
4. **保密组分**：含量达限值也应参与危害判定，但名称/CAS 可保密（注明"商业机密"，危险性须列明）。
5. **黏度条件**（吸入危害）：水性乳液黏度通常 >20.5 mm²/s，即使含 ≥10% 石脑油类也不构成吸入危害类1；该条对"水性催干剂/乳液类"尤其关键。
