# MSDS 覆写前检索输出规范与标准化骨架说明

> **文档定位**：本规范详细说明从 MSDS 标准数据库 / docx 直读检索系统导出、用于下游**覆写引擎（`msds_overwrite_engine.py`）**执行覆写前所必须依赖的**标准检索输出结构与标准化骨架体系**。
> **结构版本**：v2.0 (2026-08-18)
> **结构指纹**：`e50fdef9f3cf9aa5`（锁定 17 节骨架、114 个宽表字段、116 个标准字典项）

---

## 核心设计原则

1. **基于结构找内容，非基于内容找结构**：输出骨架 100% 固定，严格参照 GB/T 16483 国标与定稿模板 `PEA-4139 MSDS_CN 冠志 模板.docx`，数据按结构一一对应填入，不随任何文档异构而漂移。
2. **纯净化与抗污染**：有真实有效数据时严格剔除「无数据/不适用」等占位拼接；通栏说明行不带前缀伪标签。
3. **S9 瘦身输出口子**：Section 9 提供仅输出有效值项的瘦身机制，`9.37 其他信息` 始终严格置于理化特性最末项，避免覆写时生成冗余空行。
4. **一等公民子表与通栏行序锁定**：S3 成分（3列/4列）、S8.2 生物限值（5列）以结构化对象传递，S15 法规信息单列通栏严格锁定物理行序。

## 三、覆写前检索调用指令全集

```powershell
# 1. 导出当前型号标准覆写写入项 JSON (直通覆写引擎):
python tools/build_msds_db.py <db> --model EC-1801 --write-items --out "write_items_EC1801_pure.json"

# 2. 检索指定型号骨架树 (仅输出 S9 有效值项):
python tools/build_msds_db.py <db> --model EC-1801 --sections 1,3,8,9,15 --s9-clean

# 3. 关键词检索 (快速定位库内型号与节位置):
python tools/build_msds_db.py <db> --model-search "闪点"

# 4. 执行覆写引擎合成 Word:
python msds_overwrite_engine.py `
  --template "PEA-4139 MSDS_CN 冠志 模板.docx" `
  --write-items "write_items_EC1801_pure.json" `
  --out "EC-1801_MSDS_CN_冠志_覆写输出.docx"
```
