# 数据库检索功能 · 需求文档

> 状态：需求梳理完成，待用户确认后开发
> 关联库：`数据库/正式库/Data Base/msds_standard.db`（SQLite 四表：schema_field / msds_model / msds_field / msds_wide）

## 1. 定位

在「MSDS 结构读取」检索工具中新增**数据库检索**能力：

- **功能独立**：数据库检索与 docx 直读检索（现有 导入→读取→显示→检索 流程）是两个独立功能，互不依赖；数据库检索只读 SQLite 库内已有数据，不涉及现场导入 docx。
- **唯一索引**：产品型号（`msds_model.model`）。
- **呈现范本**：输出格式与呈现样式复用现有检索工具（GUI 三列表 / CLI 三级树 / JSON / TSV）。

## 2. 检索模型

| 入口 | 输入 | 行为 | 输出 |
|---|---|---|---|
| 按型号检索 | 型号名（如 `PEA-4139`，支持模糊） | 精确/模糊匹配库内型号 | 该型号完整 17 节结构（父子级+标签+值），含来源/统计信息 |
| 按关键词检索 | 任意词（空格多词 AND） | 匹配 标签 / 字段内容 / 标准字段名 / 节号 | 命中型号清单 + 命中位置（节/标签），可再进详查 |

- 支持**范围过滤**：`--sections 1,9` 等限制展示/检索的节范围。
- 型号列表：GUI 端左侧提供库内全部型号一览（点选进详查）。

## 3. 界面与输出（范本对齐现有样式）

### GUI：新增「库检索」模式（与现有单文档流程并行）

工具栏: [📚 库检索(模式切换)] [型号输入框] [🔍 检索] [✕]

        节标题深蓝通栏行 / 总结句跨列行 / 子表块 / 成分表 / S11 国标大类）
状态栏: 型号 · 来源(docx|xlsx) · 入库时间 · 明细行数 · 命中提示

### CLI：新增子命令（输出对齐 `--extract`）

```powershell
python tools/build_msds_db.py <db> --model PEA-4139              # 三级父子级树文本
python tools/build_msds_db.py <db> --model PEA-4139 --json        # 嵌套 JSON（同 render_tree_json）
python tools/build_msds_db.py <db> --model PEA-4139 --tsv         # 扁平 TSV（节|大标题|小标题|标签|字段）
python tools/build_msds_db.py <db> --model PEA-4139 --sections 1,9   # 范围过滤
python tools/build_msds_db.py <db> --model-search 关键词 [--sections 1,9]   # 命中清单
python tools/build_msds_db.py <db> --models                       # 型号列表
```

## 4. 数据语义

| 库表 | 用途 |
|---|---|
| `msds_model` | 型号索引（唯一键 model）、来源 source、sha256、统计、入库时间 |
| `msds_field` | 父子级明细 → 渲染三列表（sub=大标题 / field=标签 / note=总结句 / component=成分 / subtable=子表，sub_header·sub_rows JSON） |
| `msds_wide` | 型号总览 / 跨型号对照 |
| `schema_field` | 标准字段字典（检索辅助：标准字段名命中） |

## 5. 关键约定（用户确认）

1. **入口**：GUI + CLI 都要。
2. **多来源**：数据库检索与 docx 检索功能独立；库内型号当前**无多来源**（一个型号一条记录），source 字段保留供追溯；若未来出现同型号多条，按来源分别列出（不做合并）。
3. **范围过滤**：支持 `--sections`。
4. **型号列表预览**：GUI 左侧型号列表区。
5. **数据写入方式未定**：入库管线（通过何种连接/命令写入数据）由用户后续决定；检索功能只读库，不依赖写入方式。
