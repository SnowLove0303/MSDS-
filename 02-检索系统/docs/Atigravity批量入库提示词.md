# 入库规范要点（入库层已自动实现，你只需核对结果）
- **基于结构找内容**: 数据按骨架填，结构不随数据变；清单外标签数据自动丢弃（无数据）。
- **归一化**: 标签经 `standard_name` 归一到清单字段（同义别名/单位括号剥离）;
  S11/S12 子项（方法/物种/NOAEL 等）归并到国标大类; S15 任意法规名归并「法规条目」。
- **占位符**: 成分 CAS 占位（商业机密/Trade secret）与含量占位（>n、无数据）原样保留。
- **总结句槽位(13)**: S11 产品说明·成分参考引导段 / S12 同 / S13 法规定义·欧盟废弃细则 /
  S15 指引段·说明段·法规条目 / S16 免责声明 —— 有内容显示内容，无内容写「无数据」。
