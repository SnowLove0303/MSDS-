# MSDS 标准化库 · 17 节合格标准

> **唯一基准：PEA-4139 MSDS_CN 冠志 模板.docx**
> 本文档定义"完美符合 PEA-4139 结构化呈现"的 MSDS 判定标准。合格 = 该文件可原样进入标准库（无需推断/覆写）；不合格 = 需修复后入库或排除。
>
> 判定分三级：
> - **硬性**（缺失/不符 = 一票否决，不合格）
> - **软性**（缺失 = 警告，但关键字段满足时仍可合格）
> - **否决项**（出现即不合格，如跨节内容错位）

## 合格判定总则

1. **节完整性**：必须检出 16 节（S0 页眉页脚 + S1–S15）。S16 可选。
2. **节顺序**：节必须按 0→15 顺序排列，不得跳节/并节。
3. **字段结构**：每节必需字段齐全，且字段有值（值可为"无数据"，但不可为空标签）。
4. **内容规范**：S2 危险性说明必须含 H 代码、防范说明必须含 P 代码；信号词为"警告/危险"。
5. **无错位**：字段内容必须属于其所属节，不得出现跨节内容（如 S2 塞入急救/消防/储存内容）。
6. **无粘连**：标签不得粘连值（如"危害性说明:...防范说明"）、不得值混入标签（如"乳白色液体"当标签）。

## 合格判定规则（自动化筛选）

> **以模板自身为基准**：实测 PEA-4139 模板自身判定为 warn（软缺 9 个字段，
> 见下表），说明这些软性字段是模板的固有缺失，不是文件缺陷。因此"完美合格"
> 的软性标准 = **软缺不超过模板自身缺失**，而非"零软缺"。

### 模板自身软缺基线（TEMPLATE_SOFT_GAP）

| 节 | 模板自身也缺失的软性字段 |
|---|---|
| S1 | 产品名称 / 应急电话 / 电子邮件 |
| S2 | 标签有害成分 |
| S3 | 组分 / CAS号 |
| S9 | 相对密度 / 熔点·凝固点 |
| S15 | 其它的规定 |

一份 MSDS 判定为"完美合格"（可原样入标准库），须同时满足：

1. **16 节齐全**（S0–S15），S16 可选。
2. **每节硬性字段全部命中**（见各节"必需字段"标为硬性的项）。
3. **否决项全部未触发**（跨节错位 / 标签粘连 / 值混入标签 / H·P 代码缺失 等）。
4. **软性缺失 ⊆ 模板软缺基线**（即文件缺失的字段不超出上表范围）。
5. 序号（如 2.1/4.1）与模板一致；S9 序号入库时连续矫正为 9.1→9.N。

### 判定输出
| 等级 | 含义 | 处置 |
|---|---|---|
| ✅ 完美合格 | 硬性全命中 + 否决未触发 + 软缺⊆模板基线 | **直接入标准库** |
| ⚠️ 待修复 | 硬性命中但软缺超出模板基线（多缺字段） | 记录差异，走推断/覆写补齐 |
| ❌ 不合格 | 节缺失 / 硬性字段缺失 / 否决项触发 | 排除出标准库，待覆写重建 |

### 全库实测（766 文件）
| 分级 | 数量 | 说明 |
|---|---|---|
| 非MSDS | 122 | 检出节数 <8（tds 等），排除不参与 |
| ✅ 完美合格 | 6 | PU-2304/2306/7205/7206(冠志+国彩)/PUA-7216，软缺≤模板 |
| ⚠️ 待修复 | 14 | 软缺比模板多 S2其他危险 + S9饱和蒸气压 |
| ❌ 不合格 | 624 | 硬缺/否决/节缺失，需推断+覆写重建 |
