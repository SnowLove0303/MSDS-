# MSDS 标准检索信息输出格式规范（覆写引擎标准输入契约）

> **文档定位**：本规范定义了从 MSDS 数据库检索系统 / docx 直读检索系统导出的标准结构化数据格式，作为**覆写引擎（`msds_overwrite_engine.py`）**的标准输入数据契约。
> **版本**：v1.0 (2026-08-18)
> **结构指纹**：`e50fdef9f3cf9aa5`（锁定 17 节骨架、114 个宽表字段、116 个标准字典项）

---

## 核心设计原则

1. **基于结构找内容**：输出结构完全固定，严格对应 GB/T 16483 规范与定稿模板骨架；
2. **双模式输出**：
   - **模式 A（覆写直通写入项模式 · `write_items.json`）**：专供覆写模块直接消费，仅输出有实际有效数据的项（S9 及全节自动剔除「无数据/不适用」），避免覆写时生成冗余空行；
   - **模式 B（17 节全景骨架三级树模式 · `skeleton_tree.json`）**：供全量数据审计、比对与推断引擎消费，包含 17 节完整父子级层级。
3. **9.37 顺序铁律**：Section 9 中 `9.37 其他信息` 必须始终作为理化特性的序号最末项输出。

---

## 一、模式 A：覆写引擎直通写入项标准格式（`write_items.json`）

这是 `msds_overwrite_engine.py` 直接消费的 JSON 数据结构。

### 1. 顶级数据结构规范

```json
{
  "sections": {
    "0": [ /* S0 页眉页脚列表 */ ],
    "1": [ /* S1 物料及供应商列表 */ ],
    "2": [ /* S2 GHS 危险性概述列表 (可选/推断) */ ],
    "3": { /* S3 成分对象结构 (含产品类型与成分列表) */ },
    "4": [ /* S4 急救措施列表 */ ],
    "5": [ /* S5 消防措施列表 */ ],
    "6": [ /* S6 意外泄漏措施列表 */ ],
    "7": [ /* S7 操作和储存列表 */ ],
    "8": [ /* S8 接触控制列表 (含生物限值子表) */ ],
    "9": [ /* S9 物理和化学特性列表 (已瘦身过滤) */ ],
    "10": [ /* S10 稳定性和反应性列表 */ ],
    "11": [ /* S11 毒理学信息列表 */ ],
    "12": [ /* S12 生态学信息列表 */ ],
    "13": [ /* S13 废弃处置列表 */ ],
    "14": [ /* S14 运输信息列表 */ ],
    "15": [ /* S15 法规信息列表 */ ],
    "16": [ /* S16 其他信息列表 */ ]
  },
  "keep_structure": [2],
  "empty_policy": "warn"
}
```

### 2. 各节字段详细格式契约

#### (1) 通用平铺字段节点格式（S0, S1, S2, S4~S7, S9~S16）
每个字段为一个 Object：
```json
{
  "seq": "9.1",          // 字段序号 (若无序号传空字符串 "")
  "label": "外观",        // 字段标准标签名称
  "value": "黄色透明液体"   // 字段内容 (多行以 \n 分隔，不包含"无数据"等无效占位)
}
```

#### (2) S0 页眉/页脚（特殊规则）
```json
"0": [
  { "seq": "", "label": "产品名称", "value": "EC-1801" },
  { "seq": "", "label": "产品型号", "value": "EC-1801" }
]
```

#### (3) S3 成分/组成资料（对象结构）
S3 在覆写契约中不是平铺列表，而是专门的对象字典：
```json
"3": {
  "产品类型": "混合物",
  "components": [
    {
      "name": "氢化甲醛与苯胺的聚合物",
      "cas": "135108-88-2",
      "conc": "10-25%"
    },
    {
      "name": "聚醚二胺",
      "cas": "商业机密",
      "conc": "5-10%"
    },
    {
      "name": "三亚乙基四胺(TETA)",
      "cas": "112-24-3",
      "conc": "1-3%"
    }
  ]
}
```

#### (4) S8.2 生物限值（子表在平铺流中的表达）
```json
{
  "seq": "8.2",
  "label": "生物限值",
  "value": "",
  "subtable": {
    "header": ["组分名称", "标准来源", "生物监测指标", "生物限值", "采样时间"],
    "rows": [
      ["二甲苯", "ACGIH(2009）", "尿中甲基马尿酸", "1.5g/g肌酐", "班末"]
    ]
  }
}
```

#### (5) S9 物理和化学特性（瘦身过滤规则）
- 仅输出具有真实有效数据的字段项；
- 值为 `无数据`、`不适用`、`无`、`未提供`、`N/A` 的项**一律过滤剔除**；
- 序号按标准序列输出，`9.37 其他信息` 若有内容则置于末尾。

## 三、调用与输出代码 API 对接说明

### 1. Python 核心代码获取输出
```python
from core.msds_db import open_db, model_to_write_items, render_model_json

db = open_db(".../msds_standard.db")

# 模式 A: 获取覆写直通写入项字典 (自动瘦身过滤无数据项)
write_items_dict = model_to_write_items(db, model_id=1, s9_active_only=True)

# 模式 B: 获取 17 节全景骨架树 JSON
skeleton_json_str = render_model_json(db, model_id=1)
```

### 2. CLI 命令行导出输出
```powershell
# 模式 A: 导出覆写写入项 JSON (直通覆写模块)
python tools/build_msds_db.py <db> --model EC-1801 --write-items --out "write_items_EC1801.json"

# 模式 B: 导出 17 节全量骨架树 JSON
python tools/build_msds_db.py <db> --model EC-1801 --json --out "skeleton_EC1801.json"

# 模式 B (S9 瘦身版): 仅导出有值项的骨架树 JSON
python tools/build_msds_db.py <db> --model EC-1801 --json --s9-clean --out "skeleton_clean.json"
```

### 3. 直接供覆写引擎执行
```powershell
python msds_overwrite_engine.py `
  --template "PEA-4139 MSDS_CN 冠志 模板.docx" `
  --write-items "write_items_EC1801.json" `
  --out "EC-1801 覆写输出.docx"
```
