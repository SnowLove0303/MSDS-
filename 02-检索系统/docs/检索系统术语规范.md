# 检索系统术语规范

> 本文件定义 MSDS 结构读取·检索系统的统一术语, 供界面、导出、代码注释、文档
> 与团队交流共用同一口径. 术语一旦变更, 需同步更新本文件与全部引用点。

## 四个核心术语

| 术语 | 代码字段 | 含义 | 示例 |
|---|---|---|---|
| **序号** | `seq` | 字段编号 (节内连续编号, 如 11.5) | `11.5` |
| **标签** | `label` | 字段名称 (去序号后的名字) | `致突变性` |
| **字段** | `value` | 字段内容文本 (标签对应的实际内容) | `多数细菌回复突变试验及染色体畸变试验结果为阴性。 部分体外基因突变试验结果存在差异。` |
| **父子级** | 层级结构 | 节 → 大标题/小标题 → 标签 → 字段 的多级归属关系 | `11.毒性资料 - 11.1 急性毒性 - 吸入： 半数致死浓度（LC50）/4 h/大鼠： ＞1.5 mg/L（气溶胶）。` |

## 一句示例

```
11.5 致突变性：多数细菌回复突变试验及染色体畸变试验结果为阴性。 部分体外基因突变试验结果存在差异。
└────┘ └───────┘ └────────────────────────────────────────────────────────────────────┘
 序号   标签                                 字段
```

```
11.毒性资料 - 11.1 急性毒性 - 吸入： 半数致死浓度（LC50）/4 h/大鼠： ＞1.5 mg/L（气溶胶）。
└──┬───┘   └────┬─────┘  └──────────────────────────────────────────────┘
  节          大标题                 小标题 + 字段
                    └────────────── 父子级 (多级归属) ──────────────┘
```

## 术语与代码结构映射

| 概念 | GUI 三列表 | 数据模型 (core/structure.py) | 分层树 (core/extract.py) |
|---|---|---|---|
| 节 | 节标题行 | `SectionData` | `SectionNode` |
| 父子级 (大标题/小标题) | 标题列 (sub 行) | `SectionRow(kind="sub")` | `BigTitleNode` |
| 序号 | 序号列 | `SectionRow.seq` / `FieldData.label` 前缀 | `FieldNode` 归属的 `BigTitleNode.seq` |
| 标签 | 标签列 | `SectionRow.label` / `FieldData.label` | `BigTitleNode.title` / `FieldNode.label` |
| 字段 | 字段列 | `SectionRow.value` / `FieldData.value` | `BigTitleNode.value` / `FieldNode.value` |

## 各层级的统一写法

| 位置 | 写法 |
|---|---|
| GUI 三列表 | `序号 | 标签 | 字段` |
| TSV 表头 | `节 \| 大标题 \| 小标题 \| 标签 \| 字段` |
| 代码注释/文档 | 一律用「序号」「标签」「字段」「父子级」, 不用「标题列/内容列」 |
| JSON 导出 | 程序契约键保持 `seq` / `label` / `value` 不变 (覆写引擎依赖), 本文件为映射依据 |

## 检索范围 (scope) 术语对照

| CLI/API 取值 | 含义 | 术语 |
|---|---|---|
| `label` | 只匹配标签 | 标签检索 |
| `value` | 只匹配字段内容 | 字段检索 |
| `all` | 标签 + 序号 + 大小标题 + 字段 | 全字段检索 |
| `section` | 按节号精确匹配 | 节号检索 |
