# MSDS Word 覆写流程、规范与全景注意事项

> **文档定位**：本规范全面阐述 MSDS Word 覆写模块（`msds_overwrite_engine.py`）的核心覆写流程、标准技术规范、操作边界以及全流程注意事项，用于指导自动化覆写流水线、推断引擎输出对接与人工质检。
> **基准模板**：`F:\正式项目与模块化内容\冠志\MSDS\03-数据库\正式库\推导方案\PEA-4139 MSDS_CN 冠志 模板.docx`（调优定稿版）
> **规范版本**：v2.0 (2026-08-18)
> **结构指纹**：`e50fdef9f3cf9aa5`（锁定 17 节骨架、114 个宽表字段、116 个标准字典项）

---

## 一、核心原则与设计哲学

1. **以模板为准（模板驱动 · Template-Driven）**：
   - 模板的**序号、标签、单元格排版、字体字号（如西文 Times New Roman + 中文宋体/Arial 混合）、边框样式**是覆写输出的骨架与最高契约；
   - 覆写引擎的核心是**复用模板物理行、更新值单元格**，严禁肆意破坏模板既有排版。
2. **基于 Schema 标准名的 1:1 精准对齐**：
   - 模板行标签与写入项通过 `core/schema.py` 归一化映射为统一的 `std_name` 进行匹配，杜绝因冒号、破折号、全半角空格差异而导致的“幽灵新增行”或“重复追加行”。
3. **闭环校验与数据零残留**：
   - 覆写完成后必须自动调用结构读取器 `read_msds` 读回生成的 docx 文档，进行 100% 逐节逐字段校验，确保输入与输出严格一致。

## 二、MSDS 标准覆写操作全流程

```
┌─────────────────────────┐
│ 1. 数据准备与纯净化导出   │ ──► 从数据库/推断引擎导出 write_items.json (S9瘦身/剔除占位/结构化子表)
└───────────┬─────────────┘
            ▼
┌─────────────────────────┐
│ 2. 模板物理行预解析与映射 │ ──► 读取基准模板，通过 core.schema 对 16 个表格物理行打上 std_name 标签
└───────────┬─────────────┘
            ▼
┌─────────────────────────┐
│ 3. 专属管线多策略执行覆写 │ ──► S0(页眉页脚子串替换) / S3(成分增删) / S8(手套材质+生物限值) /
└───────────┬─────────────┘     S9(瘦身覆写+9.37置末) / S15(行序锁定) / S1~S16(两列标准值格更新)
            ▼
┌─────────────────────────┐
│ 4. 排版护栏与边框衔接修复 │ ──► 继承排版空格、多 run 混合字体、首尾行内外边框修正 (fix_new_row_borders)
└───────────┬─────────────┘
            ▼
┌─────────────────────────┐
│ 5. 闭环校验与归档保存    │ ──► read_msds 读回校验 100% OK ➔ 保存 docx ➔ 记录操作日志
└─────────────────────────┘
```

### 1. 命令行标准调用指令
```powershell

```

## 三、分节覆写与字段匹配技术规范

### 1. S0 页眉 / 页脚替换规范
- **页眉表格**：精确定位含型号占位符的单元格，替换为目标型号（如 `EC-1801`），保留单元格居中对齐与边框；
- **页眉段落**：替换 `Version: Vx.x` 中的版本号字符；
- **页脚表格**：精准替换 `公司名称`、`产品型号`、`修订日期` 文本，**严禁破坏 `页码: PAGE / NUMPAGES` 动态域代码**。

### 2. S1 ~ S2 通用两列字段规范
- **父级字段列留空**：`1.1 产品名称`、`1.3 供应商信息`、`2.1 紧急情况概述` 仅作为视觉与层级分组，值单元格必须保持留空；
- **中文名称与型号合并规则**：若产品名称仅为纯型号代码，中文名称应呈现为 `中文品名 + 型号`（如 `水性环氧固化剂 EC-1801`）；
- **S2 危险性说明与防范说明**：防范说明（P 代码）按 `预防措施 / 事故响应 / 安全储存 / 废弃处置` 分段换行呈现；保持模板双 `2.5` 序号原样。

### 3. S3 成分/组成资料（复合表格专属管线）
- **表头保护**：第 3 行 `化学品名称 | CAS编号 | 含量%（w/w）` 100% 锁定；
- **动态行同步**：根据 `components` 数组长度动态增加或删除成分数据行；
- **格式继承**：新增成分行完整继承首个成分行的单元格宽度、宋体字号及文本水平居中格式；占位 CAS（商业机密/Trade secret）与含量（>n、10-25%）原样保留。

### 4. S8 接触控制/个人防护（手套材质与生物限值专属管线）
- **手套材质行（物理行 5~7）**：`氟化橡胶 –FKM:`、`丁基橡胶 –IIR：`、`丁腈橡胶 – NBR：` 必须 1:1 精确命中模板第 5、6、7 物理行并覆写其第 2 列值格，**严禁在下方新增重复行**；
- **8.2 生物限值子表（物理行 11~13）**：
  - 物理行 11 `8.2 生物限值：`（通栏父级）与物理行 12 **5 列表头**（`组分名称 | 标准来源 | 生物监测指标 | 生物限值 | 采样时间`）**绝对受保护保留**；
  - 若有真实生物限值数据，按行填入；若无数据，必须写入一行“未建立”或保留 1 行空表格行，**严禁删除表头**。

### 5. S9 物理和化学特性（瘦身与置末规范）
- **智能瘦身口子**：覆写时默认开启 `s9_active_only=True`，对 `无数据`、`不适用`、`未提供`、`N/A` 等无效占位字段执行静默过滤，避免 Word 页面因全量 37 字段而冗长；
- **`9.37 其他信息` 顺序铁律**：`9.37 其他信息` 必须始终作为 Section 9 的最末项输出/覆写。

### 6. S11 / S12 毒理与生态学信息（混合通栏与大类归纳）
- **通栏引导段保护**：`该产品无可用的毒理学/生态学研究。` 与 `以下为...的参考数据：` 属于固定通栏说明槽位，根据数据按需填充或保留，不破坏下方 11.1~11.10 / 12.1~12.3 的两列排版。

### 7. S15 法规信息（单列通栏行序严格锁定）
- **物理行序绝对锚定**：
  ```
  row 0: 15. 法规信息              (节标题)
  row 1: 物质或混合物的相关安全...  (指引段)
  row 2: 其它的规定：              (说明段标题)
  row 3: 符合下列法规要求：        (说明段标题)
  row 4 ~ N: GB/T 16483... 等法规条目 (单列条目)
  ```
- 法规条目必须严格在 `row 3` 下方顺序展开，**严禁倒置至顶部**，单元格严禁包含 `指引段：`、`法规条目1：` 等前缀伪标签。

## 四、排版与格式护栏（Formatting Guards）

1. **字体与字号混合继承**：
   - 标签格前导序号（如 `9.1`、`11.5`）继承 Times New Roman / 10.5pt 加粗；
   - 中文标签文本继承 宋体/Arial 12pt 加粗；
   - 覆写值格内容继承模板正文宋体 12pt（不加粗）。
2. **排版空格围栏（Spacing Fence）**：
   - 模板中用于对齐的制表符 `\t` 或多空格（如 `9.2  嗅觉阈值：      `），覆写时只替换文字本身，保留前导与尾随排版空格。
3. **边框连续性修复（Borders Continuity）**：
   - 当表格发生增删行时，自动触发 `fix_new_row_borders`，确保新增块首行顶部接上邻底边、块末行底部接下邻顶边、块内部使用虚线分隔（`dotted`），彻底杜绝断线、粗框或框线缺失。

## 五、重要注意事项与避坑指南

1. **模板文件唯一性**：
   - 覆写操作必须以推导方案调优定稿版 `PEA-4139 MSDS_CN 冠志 模板.docx` 为输入，禁止使用未调优的历史草稿版（旧版 S8 会产生结构冲突）。
2. **严禁手写 SQL 绕过写入项**：
   - 覆写引擎必须消费符合模式 A 契约的 `write_items.json`，确保数据经过清洗、去重和 Schema 对齐。
3. **校验失败即阻断**：
   - 若 `verify_output` 报告 `[FAIL]`，说明生成文档与输入数据存在偏差（缺失字段或值不匹配），必须排查模板标签或写入项键名，不可直接发布。
4. **成分 CAS/含量原样保护**：
   - 对商业机密占位符（`商业机密`、`Trade secret`、`无数据`）必须原样写入，禁止篡改为特定空值。
