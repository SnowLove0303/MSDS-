# 冠志 MSDS 正式版 Web SaaS —— 交互页面功能规划

> **版本**: v1.0（2026-08-19 决策会定稿）
> **定位**: 企业级内网多用户 Web 工作台（SaaS 形态）
> **技术栈**: FastAPI（后端，复用既有 Python 模块）+ Vue3（前端）+ SQLite（业务库）
> **前置**: 08-正式版程序 第一阶段 Web 原型（server.py / index.html / app.js）

---

## 1. 产品定位

**一句话**：把散落在 CLI / 桌面 GUI / 一次性脚本里的 MSDS 全链路能力，收敛为一个**内网多用户 Web 工作台**——内部人员（EHS / 技术文档 / 品控）在浏览器中完成 **两条业务闭环**，全程可追溯、可审计、受权限管控。

### 1.1 与第一阶段原型的本质差异

| 维度 | 第一阶段原型 | 正式版 Web SaaS |
|---|---|---|
| 使用形态 | 单机 127.0.0.1，仅本机 | 内网服务器部署，多用户浏览器访问 |
| 账号权限 | 无 | 账号 + 角色 + RBAC，编辑权限与白名单绑定 |
| 业务链路 | 检索 / 单段表单 / 单模板覆写 | 存量重写闭环 + 新产品创建产出入库 |
| 长任务 | 同步执行 | 异步任务队列（批量覆写 / 批量转换 / 入库） |
| 数据流转 | 本地路径操作 | 服务端归档（写入项、覆写日志、校验报告、产出物） |
| 审计 | 无 | 全操作审计日志 |

### 1.2 首版范围（决策会确认）

- **链路 A｜存量重写闭环**：检索诊断 → 白名单内编辑 / 表单录入 → 覆写产出 → 闭环校验 → 下载交付
- **链路 B｜新产品创建产出与入库**：表单录入 → 生成写入项 → 覆写产出 → 校验 → **写入正式数据库**（新增能力）
- **AI 推导引擎暂不接入 Web**：继续使用既有 CLI / skill（判断skill）流程，后续 S3 阶段再议

**技术要点**
- 后端：FastAPI + uvicorn，复用 `02-检索系统`、`05-覆写模块` 全部逻辑；新建 `core/auth.py`、`core/rbac.py`、`core/tasks.py`、`core/audit.py`、`core/ingest.py`（入库）
- 前端：Vue3 + Vite + Pinia + Vue Router；组件库用 Element Plus（表单项多，组件化收益大）；布局延续 saasboard 视觉基线
- 任务队列：uvicorn 内嵌队列（SQLite 任务表 + 后台 worker 线程）；批量场景够用，不引入 Celery
- 部署：内网一台服务器（Windows Server 或 Linux），FastAPI 反代，局域网访问

## 3. 页面结构与功能清单

### 3.1 页面地图（9 页面）

```
冠志 MSDS 工作台
├── ① 工作台首页            —— 库统计 / 待办 / 最近任务
├── ② 型号检索 / 库浏览      —— 检索 + 标准范式矩阵 + 批量对比
├── ③ 型号详情（17 节视图）  —— S0–S16 树形只读 + 白名单就地编辑 + 诊断
├── ④ 表单录入（S1/S3/S9）  —— 固定录入协议 + 写入项生成
├── ⑤ 覆写产出              —— 模板 / 写入项 / 覆写 / 校验 / 下载
├── ⑥ 新产品创建与入库      —— 链路 B：录入 → 产出 → 校验 → 入库
├── ⑦ 批量任务中心          —— 批量覆写 / 批量转换队列 + 进度 + 结果下载
├── ⑧ 数据管理              —— 法规库 / CAS 库 / 成分危害 / 标准字段 / 模板
└── ⑨ 系统管理              —— 账号 / 角色 / 权限 / 审计日志 / 任务监控
```

### 3.2 逐页功能明细

#### ① 工作台首页
- 库统计卡片：总型号数、字段映射覆盖率、CAS 物质数、待重构（不合格）型号数
- 待办区：诊断出的问题型号（缺失章节 / 空值 / 跨章节污染）列表，点击直达详情
- 最近任务：本人最近 10 条覆写 / 入库 / 批量任务状态
- 快捷入口：存量重写（选型号）、新产品创建

#### ② 型号检索 / 库浏览
- 检索条件：型号 / 标签（label）/ 字段值（value）/ 大类（scope）/ 模糊多选
- 结果表：型号、大类、章节完整度徽章（绿/黄/红）、标签数、最近更新
- 标准范式矩阵视图：行=型号，列=标准字段，无数据单元格黄色标注（复用 RET-07 范式输出）
- 批量对比：勾选多型号 → 对比表（复用 07-多格式输出 批量对比能力）
- 分页 + 导出（CSV / JSON 标准范式）

#### ③ 型号详情（17 节视图）
- S0–S16 树形结构只读展示（父子级），复用 `model_detail` / `listed_section_rows`
- 每节诊断区：命中 / 缺失 / 多余 徽章；跨章节重复污染提示（S10/S11/S12、S8 子项串值）
- **白名单就地编辑**：仅 `core/edit_policy` 允许的字段可编辑，其余只读；保存走 `msds_form_overwrite.py` 的 write_items 生成链路
- 编辑历史：该型号每次覆写 / 修改留痕

#### ④ 表单录入（S1/S3/S9）
- 按 `core.form_schema` 渲染可编辑字段；Section 9 保持冻结 37 项标准字段骨架
- 固定录入协议：
  - 多行字段以单独输入"结束"收尾
  - S3 成分：名称、CAS、含量 逐行录入（增删行）
  - S8.2 生物限值：组分名称、标准来源、生物监测指标、生物限值、采样时间
  - S15 法规条目：逐条录入
- 默认保留模板原值；输入 `!清空` 才清空字段；空值统一变为 `无数据`
- 必填校验 + 跨章节重复检测（输入阶段即拦截 S10 混入 S11 等污染）
- 生成写入项 JSON 预览，可下载

#### ⑤ 覆写产出
- 模板选择：冠志 / 国彩 × 中文 / 英文 Word 模板（固定中文模板为首版默认）
- 写入项来源：型号详情就地编辑结果 / 表单录入生成
- 执行覆写 → 回读校验（`verify_output`）→ 校验报告展示（通过 / 需复核）
- 产出物下载 + 服务端归档（docx + 写入项 + 校验报告 + 覆写日志一并留存）
- 覆写操作写入审计日志

#### ⑥ 新产品创建与入库（链路 B，首版新增）
- 创建向导：新建型号 → 选产品大类 → 表单录入（④ 复用）→ 生成写入项
- 覆写产出（⑤ 复用）→ 校验通过
- **入库**：将产出写入 `msds_standard.db`（型号 / 字段 / 大类 / 映射表），含幂等处理（型号已存在则提示覆盖或拒绝）
- 入库前二次确认（`--yes` 语义等价物），入库后回读验证落库数据
- 入库操作审计留痕

#### ⑦ 批量任务中心
- 批量覆写：勾选多型号 → 批量任务入队 → 进度条 / 队列状态 → 结果打包下载
- 批量转换（S4 启用）：中英 × 冠志/国彩 × Word/PDF 规格矩阵
- 任务历史：状态 / 耗时 / 成功失败明细 / 失败原因可定位到型号

#### ⑧ 数据管理
- 法规库条目维护、CAS 物质 / 别名增改查、成分危害速查（只读或白名单编辑，后续 S3 推导用）
- 标准字段库（schema_field）浏览，字段权限与 edit_policy 联动展示
- 模板元数据：模板文件、适用厂商 / 语言、版本

#### ⑨ 系统管理
- 账号管理：创建 / 禁用 / 重置密码
- 角色权限：角色 × 编辑白名单 × 页面访问权限（RBAC）
- 审计日志：按人 / 时间 / 操作类型检索（覆写、入库、编辑、登录）
- 任务队列监控：运行中 / 排队 / 失败重试

## 4. 权限模型（编辑白名单 × 角色）

**统一规则**（继承既有约定，禁止前端临时限制）：
- 字段权限由后端 `edit_policy` 白名单统一裁决，前端只按 API 返回的可编辑状态渲染
- 白名单字段 × 角色进一步收窄：如「操作员」可编辑白名单内字段、「审核员」可读 + 确认、「管理员」可改白名单 + 数据管理
- 未列入允许编辑范围的字段，任何角色都只能只读；请求接口越权编辑一律拒绝（后端校验，非仅前端隐藏）

| 角色 | 检索/查看 | 白名单编辑 | 覆写 | 入库 | 数据管理 | 系统管理 |
|---|---|---|---|---|---|---|
| 访客 | ✔ | ✖ | ✖ | ✖ | ✖ | ✖ |
| 操作员 | ✔ | ✔ | ✔ | ✖ | ✖ | ✖ |
| 审核员 | ✔ | ✔ | ✔ | ✔（需确认） | ✔（白名单内） | ✖ |
| 管理员 | ✔ | ✔ | ✔ | ✔ | ✔ | ✔ |

## 5. 开发规划

### 阶段划分（对齐 PRD 里程碑）

| 阶段 | 内容 | 交付标准 | 对应 PRD |
|---|---|---|---|
| **S1 工作台化**（首版） | FastAPI 骨架 + JWT 认证；页面②③④⑤⑥ 完整化：检索、诊断、白名单编辑、表单协议、覆写闭环、新产品创建入库；审计日志基础版 | 浏览器内完成 存量重写 与 新产品入库 两条闭环，闭环校验通过 | M1 完成态 + 部分 M2 |
| **S2 多用户化** | 账号/角色/RBAC、审计日志完善、产出物归档、批量任务中心（⑦⑨ 完整） | 内网多人可用，操作可追溯 | M2/M3 部分 |
| **S3 AI 推导接入**（暂缓） | 推导任务异步化 + 联网搜证 + 逐节确认 + 依据标注 | 存量重写 AI 辅助 | M3 |
| **S4 格式矩阵** | 中英 × 冠志/国彩 × Word/PDF 批量转换 + 转换校验 | 1 源 → 8 规格批量产出 | M4 |

### S1 排期建议（约 4–6 周，可按周拆解）

| 周 | 里程碑 |
|---|---|
| W1 | FastAPI 工程骨架、JWT 认证、DB 只读 API（检索 / 详情 / 统计）、Vue3 工程 + 布局 |
| W2 | 页面②检索 / 矩阵视图；页面③详情 17 节只读 + 诊断徽章 |
| W3 | 页面③白名单就地编辑（edit_policy 后端裁决 + write_items 生成）；页面④表单协议 |
| W4 | 页面⑤覆写产出闭环（模板 / 覆写 / 校验 / 下载 / 归档）；审计日志基础版 |
| W5 | 页面⑥新产品创建入库（含幂等 / 二次确认 / 回读验证）；页面①工作台 |
| W6 | 端到端联调、批量任务雏形、部署脚本、验收文档 |

### 技术风险与对策

| 风险 | 对策 |
|---|---|
| 现有模块为 CLI/桌面设计，需封装为 API | 只读查询直接包 REST；写路径统一走 write_items → 覆写引擎，不绕行 |
| 入库是全新能力（数据库目前只读使用） | 先做表结构核对 + 只写副本库联调，双库校验后再切正式库 |
| 长任务阻塞请求 | S1 即建任务表 + 后台 worker，覆写/入库全部异步 |
| 编辑权限被绕过 | 后端 edit_policy 唯一裁决 + 审计日志，前端仅渲染状态 |
| 前端表单复杂度高（成分表 / 生物限值 / 法规条目） | 复用 01-表单系统 form_schema 契约，前端组件按协议实现 |

## 6. 待确认事项（下一轮决策）
