# 数据库检索功能规划（平面查询）

> **版本**: v1.1（2026-08-19 四批需求确认定稿）
> **所属**: MSDS 正式版 Web SaaS — 页面②「型号检索/库浏览」的基础能力
> **关联文档**: [Web正式版](https://xcnch7esppuf.feishu.cn/wiki/Cn4Sw2I7aiWEPSk4xZEcBInknwe)

## 1. 功能定位

把 MSDS 数据库（`msds_standard.db` + `cas_library.db`）从"只能按型号查详情"升级为**全库平面查询**：任意字段筛选、选列、排序、对比、诊断、导出，供 EHS / 技术文档 / 品控在浏览器中直接检索与取数。新产品入库写入的也是同一批库，因此本功能天然覆盖后续新增数据。

**交付形态**：Web 页面 + FastAPI 查询 API（API 为页面所用，同时可被其他页面/脚本复用）。

## 3. 页面规划（3 个页面/视图）

### 3.1 平面查询页（主视图）
- **默认全列**：进入页面默认展示 115 列全部（用户可自行缩减）
- **按节分组选列**：按 S0–S16 节分组勾选列（可折叠），支持"全选/清空/反选"
- **任意列关键词过滤**：任意列输入关键词 LIKE 过滤
- **数值范围筛选**：数值字段（闪点/沸点/含量等）支持范围（`>60`、`20~80`）
- **按缺失筛选**：支持按字段缺失情况筛选（如"S9 缺失的型号"）
- **后端分页**：每页 50 行，服务端分页（为未来数据量扩大预留）
- **勾选对比**：勾选多个型号 → 仅显示所选型号行，同列对比
- **单元格明细深查**：点击宽表格子 → 弹窗展示该型号该字段的父子级完整结构（含多值、重复项）——宽表只作浏览摘要，信息完整依赖明细表深查
- **导出**：Excel + CSV 两种格式；范围支持"当前筛选结果"与"整库（选列）"两种
- 行点击可跳转已有型号详情页（S0–S16 树形）

### 3.2 覆盖度诊断页（独立页）
- 型号列表，展示每个型号各节（S0–S16）字段缺失数
- 支持按缺失总数/特定节缺失排序、筛选
- 点击型号展开缺失明细（缺了哪些字段）
- 顶部统计：库整体覆盖率、最常见缺失字段 TOP-N

### 3.3 CAS 物质反查页
- 按 CAS 号 / 标准名 / 别名搜索物质
- 展示物质信息（类别、登记状态、来源数、型号数）
- 列出该物质关联的所有型号（基于 `cas_model_usage` 804 条关联）
- 支持点击型号跳详情页

## 4. API 契约（草案）

| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/query/wide` | POST | 平面查询：分页 + 列投影 + 关键词过滤 + 数值范围 + 缺失筛选 + 排序；返回行数据与总行数 |
| `/api/query/wide/columns` | GET | 返回宽表列清单（按节分组元数据，含类型） |
| `/api/query/wide/detail` | GET | 单元格深查：型号+字段 → 父子级完整结构 |
| `/api/query/coverage` | GET | 覆盖度统计（型号×节缺失矩阵，支持过滤） |
| `/api/query/coverage/model` | GET | 单型号缺失明细 |
| `/api/query/cas/search` | GET | 物质搜索（CAS/名称/别名） |
| `/api/query/cas/models` | GET | 物质→关联型号列表 |
| `/api/export/wide` | GET | 导出 Excel/CSV（当前结果或整库，选列） |
| `/api/export/coverage` | GET | 导出覆盖度报告 |

## 5. 关键设计决策（已确认）

1. **宽表信息有损** → 宽表仅作浏览摘要，多值明细通过"单元格弹窗深查"从 `msds_field` 父子级表取完整结构
2. **找缺字段型号** → 独立"覆盖度诊断页" + 平面页支持按缺失筛选
3. **导出** → 当前结果 + 整库选列，Excel + CSV
4. **CAS 库** → 独立物质反查页（物质→型号）
5. **对比** → 平面表勾选后同表对比（不另建对比页）
6. **选列** → 按 17 节分组
7. **默认视图** → 全列 115 列
8. **分页** → 后端分页 50 行/页
9. **数值筛选** → 支持范围筛选

## 6. 未决事项

- 排序能力（任意列排序）在第二批未明确勾选，默认按型号 ID 排序；如需任意列排序请说明
- 数值范围筛选的字段白名单（哪些字段按数值解析）需在开发时确认
- API 认证（内网多用户：登录后使用，RBAC 访客只读）

## 7. 开发排期建议

- **D1（后端 API）**：wide 查询/列元数据/深查/覆盖度/CAS 搜索/导出，约 3–4 天

- **D3（诊断页 + CAS 页）**：覆盖度矩阵、缺失明细、物质反查，约 2–3 天
- **D4（联调）**：与 Web SaaS 骨架（登录/导航）集成，约 1–2 天
