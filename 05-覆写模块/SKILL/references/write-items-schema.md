# 写入项 JSON schema 详解

## 顶层结构

```json
{
  "keep_structure": "all",
  "empty_policy": "warn",
  "sections": {
    "0":  [ { "seq": "", "label": "Version", "value": "1.0" }, ... ],
    "1":  [ { "seq": "1.1", "label": "产品名称", "value": "EC-1801" }, ... ],
    "3":  { "产品类型": "混合物", "components": [ ... ] },
    "9":  [ { "label": "外观", "value": "黄色至浅褐色透明液体" }, ... ],
    "16": []
  }
}
```

- `keep_structure`: `"all"`（默认，全部节模板驱动）或节号列表 `[2]`。模板驱动 = 模板字段行全保留，写入项只覆写匹配值，模板多出字段保留。
- `empty_policy`: `warn`(默认，覆写空值+模板原值非空时告警)/`overwrite`(静默清空)/`preserve`(空值跳过保留模板)。
- `sections`: 键是节号字符串；值为**数组**（普通节）或**dict**（S3 成分节）。

## 字段条目字段

| 字段 | 说明 |
|---|---|
| `label` | 匹配键（必填）。归一化+字段映射后与模板标签对齐；不要求与源文件写法逐字一致 |
| `value` | 值源。多行用 `\n` 分隔（引擎按 `\n` 拆段重放，格式继承） |
| `seq` | 序号（可省）。模板驱动下复用行序号继承模板；主要用于**新增行**指定序号 |
| `delete` | `true` = 显式删除该模板行（模板驱动下唯一删行通道） |

```json
// 显式删除模板行
{ "label": "氟化橡胶 –FKM", "delete": true }
```

## S0 页眉页脚（数组）

只覆写可变字段，`物料安全数据表`/`页码` 固定标题与自动页码不可覆写：

```json
"0": [
  { "label": "Version",   "value": "1.0" },
  { "label": "产品名称",   "value": "EC-1801" },
  { "label": "公司名称",   "value": "广州冠志新材料科技有限公司" },
  { "label": "产品型号",   "value": "EC-1801" },
  { "label": "修订日期",   "value": "2025/6/18" }
]
```

## S3 成分/组成（dict 特殊格式）

```json
"3": {
  "产品类型": "混合物",
  "components": [
    { "name": "氢化甲醛与苯胺的聚合物", "cas": "135108-88-2", "conc": "10-25" },
    { "name": "聚醚二胺",               "cas": "商业机密",    "conc": "5-10" },
    { "name": "三亚乙基四胺",           "cas": "112-24-3",    "conc": "1-3" }
  ]
}
```

- 成分与模板行按顺序对齐：复用模板成分行（格式继承），多出的成分新增、少的删除；
- CAS="商业机密" 是真实源数据，保留语义，不视为缺失；
- 成分名称含空格会被引擎去空格+居中，避免换行折断。

## 各节惯例速查

| 节 | 结构 | 备注 |
|---|---|---|
| 0 | 数组（页眉页脚字段） | 页码/固定标题不可覆写 |
| 1 | 数组 | 产品名称/中文名称/化学品分类/使用建议/供应商四件套 |
| 2 | 数组 | GHS 危险性类别/标签要素/象形图/信号词/危险性说明/防范说明/其他危险 |
| 3 | dict | 产品类型 + components |
| 4~7 | 数组 | 急救/消防/泄漏/操作储存 |
| 8 | 数组 | 呼吸/手/眼睛/身体防护；note 行"8.1 暴露控制"是结构行 |
| 9 | 数组 | 22+ 个物化性质字段；S9 模板行多带排版空格，覆写保留 |
| 10~14 | 数组 | 稳定反应/毒性/生态/处理/运输 |
| 15 | 数组 | 法规行（note 行 + 法规单格行） |
| 16 | 数组 | 其他信息（通常整段 note，value 为全文或空） |

## 空值策略与 keep_structure 关系

- **模板驱动 + 写入项空值**：锚定模板行并覆写为空（默认 `warn` 告警可审计）；
- **模板驱动 + 写入项缺该字段**：模板行保留模板原值（骨架）；若该节是 `REQUIRED_FIELDS` 声明的必需字段（如 S2 信号词）会 WARN；
- **显式 delete**：模板行物理删除（避免覆盖骨架时误删）。
