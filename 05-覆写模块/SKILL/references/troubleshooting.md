# 常见问题排查

## 1. 字段被「删 + 增」而非「改」

**现象**：覆写日志里某字段显示 `删 rowN` 然后 `增 [字段]`，或大量字段靠"新增"插入，
触发 `S<N>: 写入项 X 个字段中 Y 个靠新增插入，与模板字段差异大，请核对字段映射/标准字段清单`。

**原因**：字段映射未命中 —— 写入项 label 写法 ≠ 模板标准写法，引擎在模板里找不到对应行，
于是删模板行再克隆新行。这破坏模板骨架。

**处理**：
1. 用结构读取看模板该节字段标准写法：
   ```bash
   python main.py --extract "模板.docx" --sections <节号>
   ```
2. 在 `field_maps.json` 补映射（键=源写法归一化，值=模板标准写法）：
   ```json
   "9": { "嗅觉阀值": "嗅觉阈值" }
   ```
3. 重跑覆写，日志应变回 `S<N> 改 rowN`。

## 2. S9 编号重排/错位

**现象**：输出 S9 的编号不是 9.1/9.2/... 顺序。

**原因**：写入项 seq 与模板编号冲突，引擎重建标签格时用了写入项 seq。

**处理**：模板驱动下，清空写入项 S9 的 `seq`（或留空），让引擎沿用模板编号。
模板驱动复用行本来就继承模板标签原文，不需写 seq。

## 2.5 S9 编号跳号告警（9.22→9.24）

**现象**：结构读取回读输出时报 `S9: 编号重排(禁跳号) 按文档顺序连续重编号: 9.24→9.23`。

**原因**：模板 S9 的原始编号就缺 9.23（PEA-4139 模板最后一行是 9.24 其他信息）。
模板驱动下产出与模板逐号一致，跳号是模板既有现象，**不是覆写引入的缺陷**。

**处理**：无需处理 —— 以模板为准保留模板原始编号。仅当写入项 seq 主动改变编号时才需要核对。

## 3. 模板产品特有残留

**现象**：输出仍含上一步骤产品的关键词（如用 PEA-4139 模板覆写 EC-1801，输出出现
"二乙二醇单丁醚"、"乳白色液体"、"非危险品"、手套材质行等）。

**原因**：模板/底版里还有产品特有残留行，模板驱动默认保留它们。

**处理**：
1. 残留是"有标签的 field 行"（如 S8 手套材质行）→ 写入项加 `{"label": "氟化橡胶 –FKM", "delete": true}`；
2. 残留是"无标签的 note 引导行"（如 S11/S12 的"该产品无可用的毒理学研究。"）→ 预处理底版，
   参考 `prep_ec1801_base.py` 删除；
3. 重跑并做残留扫描（见 verification.md）。

## 4. 中文标签被降级为 10.5pt（格式未标准化）

**现象**：输出标签格中文 run 字号是 10.5pt，而模板标准是中文 12pt。

**原因**：覆写通路把标签格合并成单 run，或继承时取错 run（如 S9 三 run 行取到尾部空格 run
Times New Roman 10.5pt）。

**处理**：`set_label_text` 已保证中文标签继承模板最后一个**含非空白文本**的 run（12pt）。
若仍异常，检查该模板行 run 结构，确认中文 run 与尾部空格 run 是分开的。
改引擎后跑一次完整覆写 + 格式签名验证（verification.md）。

## 5. 空值覆写告警

**现象**：`[WARN] S<N> 改 ... '' -> '' 模板原值非空，空值覆写`。

**原因**：写入项含空值字段，默认 `warn` 策略会清空模板并告警。

**处理**：确认该字段是否真的应为空。模板默认值若是**有意义的法定值**（如信号词"警告"）：
- 写入项不输出该字段（模板保留默认值），或
- 顶层 `"empty_policy": "preserve"`（空值跳过）。

## 6. 闭环校验失败

**现象**：`闭环校验失败` + `[FAIL] S<节>.<字段>: 期望... 实际...`。

**处理**：
1. 逐条看 FAIL —— 期望=写入项值，实际=输出读回值；
2. 若输出缺字段 → 检查该字段是否因映射未命中被当新增插到了错误位置；
3. 若值不同 → 可能是排版空格残留（空值覆写会清空格）或换行差异；
4. 修复写入项/映射后重跑，直到 `闭环校验通过 OK`。

## 7. 页眉页脚未更新

**现象**：输出页脚仍是模板产品名/修订日期。

**处理**：S0 走专用路径。确认写入项 `"0"` 里有对应 label（Version/产品名称/公司名称/
产品型号/修订日期）。页码是域自动生成，**不可覆写**，不要写入项里放页码。

## 8. S3 成分行折断/错乱

**现象**：成分名折断成两行，或成分行错位。

**处理**：
- 名称含空格 → 引擎自动去空格+居中，若仍异常检查模板成分单元格格式；
- 成分数量变化 → 多出的自动新增、少的自动删除；闭环校验会报 S3 成分数差异，对照修正。

## 9. 数字开头标签被误拆序号

**现象**：如化学品名 "2-丁氧基乙醇" 被 norm_field 当成序号"2"。

**处理**：`verify_output` 已登记完整标签避免漏匹配。若写入项匹配失败，检查 label 是否含
序号形态（纯数字开头），可加字段映射或调整 label 写法。

## 10. 新增字段插错位置

**现象**：模板没有的字段新增后被插到节尾或位置不对。

**处理**：用 `--ref-pick` 指定参考行决定插入位置附近格式：
- `label:中文名称` 按标签指定参考行；
- `auto`（默认）按目标 seq 就近选择相邻模板行。
写入项可给 `seq` 帮助就近定位。
