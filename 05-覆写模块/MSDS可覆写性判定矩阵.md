# MSDS 可覆写性判定矩阵

> 依据：**GB/T 17519-2013《化学品安全技术说明书 编写指南》** 16 部分内容项要求
> ＋ **全库 443 份中文 MSDS**（冠志 258 + 国彩 185，成功解析 394）逐节字段频率统计
> 用途：覆写引擎字段级可覆写性标准（模板驱动覆写的判定依据）

---

## 〇、核心原则（不可破坏）

| 项 | 判定 | 依据 |
|---|---|---|
| 16 部分标题/编号/前后顺序 | **不可覆写** | GB/T 17519-2013 §4.2.4.a "16部分的标题、编号和前后顺序不应随意变更" |
| 两列字段行标签格 | **不可覆写**（保留模板序号+标签双run原文） | 模板驱动：标签格继承模板，仅值格覆写 |
| 多列表头（S3 成分表/S8 生物限值表） | **不可覆写** | 列结构标准，覆写破坏表格语义 |
| 单格通栏 note 行 | **可整格覆写**（标签\n值） | 保留原位 |
| 引导行残留（"无可用的…研究"/EWC 等） | **prep 阶段删除** | 旧产品残留，非标准字段 |

## 二、16 节逐节判定

### S0 页眉页脚 —— 可覆写
页眉：产品名称、版本号；页脚：公司名、修订日期 → 均覆写。

### S1 化学品及企业标识 —— **全可覆写**
- 标准内容项（§3.1）：化学品标识 / 企业标识 / 应急咨询电话 / 推荐用途和限制用途
- 全库稳定 **99%**：产品名称、中文名称、化学品分类、产品使用建议和使用限制、供应商名称/地址/电话/传真
- 判定：9 字段值全部可覆写；占位符"此处填写…"覆写时替换；新模板缺"应急咨询电话"字段 → 应新增

### S2 危险性概述 —— **结构差异大，整节按模板重建**
- 标准内容项（§3.2）：紧急情况概述 / 危险性类别 / 标签要素 / 物理化学危险 / 健康危害 / 环境危害 / 其他危害
- **旧 MSDS 形态：单格文本式**（如"物质或混合物分类 GHS分类：根据GHS不属于…"），非两列字段
- **新模板形态：两列 11 行**（2.1 紧急情况概述 ~ 2.9 其他危害）
- 判定：内容可覆写（按新模板字段结构重建）；危险性类别/信号词/危险性说明/防范说明从源分类数据提取

### S3 成分/组成信息 —— **表头锁，数据行可覆写**
- 全库 **125 种标签**（成分差异最大）
- 子标题"成分"、表头"化学品名称/CAS编号/含量%（w/w）" → **不可覆写**
- 成分数据行：名称/CAS/含量 → 可覆写，行数随产品成分数增删

### S4 急救措施 / S5 消防 / S6 泄漏 / S7 操作储存 —— **全可覆写**
- S4（99%）：一般措施/误服/接触眼睛/接触皮肤/吸入
- S5（99%）：合适灭火剂/不合适灭火剂/特殊危害/消防预防措施和保护设备
- S6（99%）：人员预防措施、应急程序/环境保护措施/污染物收集和清除的方法
- S7（99%）：安全操作防范/安全储存条件
- 判定：字段标签全库稳定，值格全部可覆写

### S8 接触控制和个体防护 —— **部分可覆写 + 需补充标准字段**
- 稳定 **99%**：呼吸系统防护/手部防护/防护手套合适材料/建议/眼睛防护/身体防护 → 可覆写
- **需新增**（标准 §3.8）：职业接触限值（旧库覆盖低）/监测方法/工程控制
- 生物限值子表（8.2，5 列：组分名称/标准来源/生物监测指标/生物限值/采样时间）：**标准附录 A 表6/7 的标准结构**，数据行可覆写
- 判定：6 防护字段覆写；3 个标准字段新增；生物限值数据行覆写

### S9 理化特性 —— **稳定项覆写 + 常见项按产品 + 特有项新增**
- 稳定 **>90%**：其他信息/引燃温度/嗅觉阀值/可燃性（固态、气态）/固体含量 → 覆写
- 常见 **50-90%**（按产品有无覆写或新增）：离子性/自燃温度/燃烧值/表面张力/闪点/相对蒸气密度/动力粘度/初沸点/水溶性/蒸发速率/外观/辛醇/水分配系数/pH值
- **产品特有**（§3.9[d] 允许附加）：MFFT/玻璃化温度/有效成分/羟基含量/粘度（涂-4杯）→ 可新增
- **需新增**（标准 GB/T 16483 必列）：熔点/凝固点、爆炸上限/下限（旧库多数缺失）
- **标签写法不统一需映射**：嗅觉阀值↔嗅觉阈值、相对密度↔密度、pH值（1%/5%/10%）→pH值（1%水溶液）

### S10 稳定性和反应性 —— **可覆写 + 需补充**
- 稳定 **99%**：化学稳定性/危险分解产物/可能的危害反应 → 覆写
- **需新增**（标准 §3.10）：应避免的条件/禁配物（旧库覆盖不足）

### S11 毒理学信息 —— **⚠ 需谨慎（数据可用性判定）**
- 三种形态：① 单格文本式"请参阅以下数据…" ② 占位"该产品无可用的毒理学研究"+类似产品评估 ③ 完整两列字段
- 字段（急性毒性/主要皮肤刺激性/主要眼睛刺激性/致敏性/致突变性/致癌性/生殖毒性/吸入危险/附加信息）覆盖率仅 **53%**
- 标准 §3.11[i]：无产品数据可"酌情使用类似物质数据，并清楚说明"；§3.11[k]：**禁止无数据支持的"有毒"等一般性用语**
- 判定：**有完整毒理数据的覆写；无数据的保留"无可用研究"占位或按标准引用类似物质并注明**。不得强行填值

### S12 生态信息 —— **可覆写 + 需补充**
- 稳定 **93%**：生态毒性/持久性和降解性 → 覆写
- **需新增**（标准 §3.12）：潜在的生物累积性（BCF/Kow）/土壤中的迁移性/PBT/vPvB 评估

### S13 废弃处置 —— **可覆写 + 需补充**
- 稳定 **98%**：处理方法 → 覆写
- **需新增**（标准 §3.13）：污染包装物处置方法/废弃注意事项/不得排入下水道（旧库仅 3~4 行）

### S14 运输信息 —— **可覆写 + 需补充标准字段**
- 稳定 **92%**：公路和铁路运输；常见 **77-78%**：海上运输/空运/用户特殊注意事项 → 覆写
- **需新增**（标准 §3.14）：联合国危险货物编号(UN号)/联合国运输名称/运输危险性分类/包装类别/海洋污染物(是/否) → 非危险品填"不适用"，海洋污染物"否"

### S15 法规信息 —— **内容可覆写（依赖产品危险分类）**
- 全单格法规条目列表，无两列字段
- 法规条目随产品分类变化（是否列入危险化学品目录/职业病危害因素/重点监管名录等）
- 判定：法规列表可覆写，但内容须由**法规匹配库**基于产品分类/成分生成，不得手写

### S16 其他信息 —— **部分可覆写**
- 免责声明：可保留模板（内容通用）或覆写
- **需新增**（标准 §3.16 a-e）：编写和修订信息/缩略语和首字母缩写/培训建议/参考文献

## 三、差异类型与处理策略

| # | 差异类型 | 示例 | 处理策略 |
|---|---|---|---|
| 1 | 标签写法不统一 | 嗅觉阀值/嗅觉阈值；相对密度/密度；pH值（X%） | field_maps 映射到模板标准标签 |
| 2 | 标准字段缺失 | S9 缺熔点/爆炸上下限；S14 缺 UN 号；S8 缺职业接触限值 | 模板驱动新增行（克隆参考行） |
| 3 | 结构形态差异 | S2 单格 vs 两列；S11 三形态 | 整节按模板重建 / 按数据可用性 |
| 4 | 合并标签 | "自燃温度：闪点（闭口）："同格 | 拆分为标准独立字段 |
| 5 | 产品特有字段 | MFFT/Tg/有效成分/羟基含量/粘度 | 附加特性行，模板驱动可新增 |
| 6 | 数据缺失占位 | "无可用的毒理学研究" | 保留占位或标准引用类似物质（S11 专用） |
| 7 | 引导行残留 | "该产品无可用的…"/"二乙二醇单丁醚…参考数据"/EWC | prep 删除 |
| 8 | 表头/标题 | 成分表头、16 部分标题 | 不可覆写 |

## 五、对引擎的优化建议

1. **S11 毒理**：写入项需带"数据来源"标记（产品数据/类似物质/无数据），引擎据此决定覆写/占位/引用——避免无据填值
2. **S9 特有字段**：模板驱动新增时保留模板原序（按 Word 出现顺序），新增行插入相邻字段间
3. **S2 整节重建**：旧 MSDS 单格文本 → 需从文本解析出分类项（危险性类别/信号词/说明）再落两列字段
4. **S15 法规**：接入法规匹配库生成法规条目，引擎只落格不生成
5. **field_maps 补全**：覆盖 44 种标签变体映射（嗅觉阀值/相对密度/pH 值变体/合并标签拆分）
6. **S8 生物限值**：新增子表同步能力（数据行按组分名称定位覆写）
